## 快速开始

```bat
cd 02-源码
pip install -r requirements.txt
python 01_main.py
```

菜单 0 一键导入数据 → 1 核对（books 50 / readers 30 / borrow_logs 3000）→ 2~10 检索统计 →
11/13 GridFS 上传与清单 → 12 按 ISBN 或书名下载并校验字节与 SHA-256 → 17 分片查询对比 → 99 退出。

数据库的启动、副本集初始化、分片集群搭建与账号说明，见 `03-数据库与配置/启动与部署说明.md`；
想验证多端口多节点是否部署成功，在 `03-数据库与配置` 下执行 `python verify_topology.py`。

## 连接配置

连接串集中在 `02-源码/config.json`，业务代码不写死地址，也可以用环境变量覆盖：

```bat
REM 公开版：把 CHANGE_ME 换成你创建账号时设置的密码（cmd 里 % 要写成 %% ）
set MONGODB_URI=mongodb://libWriter:CHANGE_ME@127.0.0.1:27017,127.0.0.1:27018,127.0.0.1:27019/?replicaSet=rs0&authSource=library
set MONGODB_DB=library
python 01_main.py
```

## 完成情况（对应任务书的任务一至任务七）

- 任务一 技术选型：四类 NoSQL 差异、CAP 三场景落到借阅写入/检索/统计、两个风险与不同选型判断点
- 任务二 数据建模：逻辑结构层次、字段类型理由、索引设计（7 个索引）、borrow_logs 建模取舍
- 任务三 单据实现：十一项检索统计（命令 + 条数）、索引前后执行计划与耗时对比
- 任务四 应用开发：11 个模块、程序可复现运行、GridFS 上传/下载/字节与 SHA-256 校验
- 任务五 部署方案：一主两从、读写分离、故障转移时间线与角色变化、keyFile 认证、节点增删演练
- 任务六 分片集群：config/sh1/sh2/mongos 拓扑、hashed 分片键论证、两分片数据分布、定向与广播查询对比
- 任务七 验收交付：五条可重复执行的核验步骤 + 图形化（Compass）结果与命令行一致

详细证据见 `01-报告文档/` 与 `04-过程记录截图/`，两者逐图对应。
